# 0004. Форматы источника данных

Дата: 2026-11-14. Статус: принято.

## Решение

| Что | Формат |
|---|---|
| Токены (цвет, отступы, радиусы, типографика, анимация) | DTCG 2025.10, файлы `*.tokens.json` |
| Режимы (тема, контраст, плотность, платформа) | DTCG resolver, JSON |
| Контракты компонентов | Собственный YAML, проверяемый JSON Schema |
| Язык дизайна и решения | Markdown |

## Детали

- Свой формат токенов не вводится: DTCG — стандарт, который понимают Style Dictionary и Figma.
- Всё, чего в DTCG нет (пружинная анимация, платформенные соответствия, правила использования для агента), хранится в `$extensions` под ключом `dev.westron.*`.
- Размеры хранятся в px; pt, dp, sp и rem выводят генераторы.
- Токены в два уровня: примитивы и семантика. Уровень компонента добавляется только при необходимости.
- «Стили» отдельным форматом не описываются: это привязки токенов к вариантам и состояниям внутри контракта компонента.
- Контракт компонента описывает опции, состояния, слоты, ограничения, привязки к токенам, доступность и блок `platforms` с расхождениями по платформам. За основу схемы берётся `component.schema.json` из Spectrum.
- Движок генерации токенов — Style Dictionary 5 с собственными форматами и небольшим препроцессором резолвера.
