# DTCG 2025.10 test suite

The official conformance fixtures of the DTCG Format and Resolver modules, copied unchanged: `format/manifest.json`
and `resolver/manifest.json` list every fixture as a positive (valid) or negative (invalid) test. `TokenSchemaTests`
and `ResolverSuiteTests` run them through the schema validator and through westron's reader and resolver.
