# Токены

Токены westron в формате DTCG 2025.10 (`*.tokens.json`) и резолвер режимов — тема, контраст, плотность,
платформа (decisions/0004). Появятся в фазе 1 (issues #10–#13).

Два уровня: примитивы и семантика. Всё, чего нет в DTCG (пружинная анимация, платформенные соответствия,
правила использования для агента), лежит в `$extensions` под ключом `dev.westron.*`. Из этих файлов
генераторы в `tools/` выпускают код для платформ; руками сгенерированное не правится.
