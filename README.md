# westron

Дизайн-система для технических продуктов с кроссплатформенным ядром и нативным UI на каждой платформе.

**Статус:** фаза 0 «Каркас». Есть пакет SwiftPM, приложение-каталог для iOS и macOS со скриншотами для агента, CI и настройка Claude Code. Компонентов пока нет. Пилотный продукт — [todo-app](https://github.com/maldrakar/todo-app).

## Идея

- **Один язык дизайна и один источник данных.** Токены, контракты компонентов и документы языка дизайна лежат в этом репозитории и не принадлежат ни одной платформе.
- **Нативные библиотеки на каждую платформу.** Apple (iOS, iPadOS, macOS, watchOS) на SwiftUI, web, Linux (GNOME: GTK4 + libadwaita), позже Android (Compose).
- **Одинаковые имена.** Значения вариантов, размеров и состояний генерируются из контракта, поэтому совпадают на всех платформах.
- **Системные контролы важнее своих.** Если на платформе есть нативный компонент, westron даёт для него стиль и расширения, а не замену.

```swift
Button("Сохранить") { save() }
    .buttonStyle(.primary, size: .m)
```

## Порядок работы

Пилотная платформа — Apple. Компоненты сначала появляются на SwiftUI, затем переносятся на web и Linux по тем же контрактам.

Фазы ведутся как [milestones](../../milestones), задачи — как [issues](../../issues). Каждый компонент проходит три точки утверждения человеком: контракт, матрица скриншотов, релиз.
